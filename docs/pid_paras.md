### **第二部分：PID调参思路与实用指南**

PID调参是一门艺术，但遵循科学的方法能让过程更高效。您的实时图表是调参最有力的工具。

**核心目标**：找到一组 `Kp`, `Ki`, `Kd` 参数，使得系统在受到扰动后，能够**快速、平稳、准确**地回到目标状态（即误差为0）。

**理解三个参数的作用**：

1.  **Kp (比例 - Proportional)**:
    *   **作用**: 主要负责**响应速度**。`Kp`越大，对当前误差的反应越剧烈，系统响应越快。
    *   **直观表现**: 在图表上，当误差突然出现时，`Kp`会立即产生一个大的输出。
    *   **问题**: `Kp`过大会导致系统**超调**（overshoot），即冲过目标点，并在目标点附近来回**振荡**。如果太大，甚至会导致系统不稳定。

2.  **Ki (积分 - Integral)**:
    *   **作用**: 主要负责**消除稳态误差**。如果系统长时间存在一个微小的、无法被`Kp`消除的误差（例如，由于持续的水流阻力），积分项会累积这个误差，并产生一个持续的力来对抗它，直到误差为0。
    *   **直观表现**: 在图表上，如果误差曲线长时间不回到0，积分项的贡献会逐渐增加，拉动输出曲线。
    *   **问题**: `Ki`过大会导致**积分饱和**，使得系统响应变慢，并且在扰动消失后，系统恢复缓慢，也容易引起超调。

3.  **Kd (微分 - Derivative)**:
    *   **作用**: 主要负责**抑制振荡**和**预测未来**。它观察误差的变化速率（导数），如果误差正在快速减小，`Kd`会产生一个反向的力（像“踩刹车”），从而减小超调和振荡。
    *   **直观表现**: 在图表上，当误差曲线快速变化时（斜率大），`Kd`的贡献最明显。它能让输出曲线在接近目标时提前“收敛”。
    *   **问题**: `Kd`对噪声非常敏感。如果您的传感器数据噪声很大，过大的`Kd`会让输出剧烈抖动。

**系统性调参步骤 (Ziegler-Nichols 思想的简化版)**：

1.  **准备工作**:
    *   **独立调节**: 每次只调节一个轴（例如，只调Yaw轴）。可以暂时在代码中让AUV保持其他轴稳定，专注于一个。
    *   **从零开始**: 将 `Ki` 和 `Kd` 都设置为 `0`。

2.  **第一步：调节 `Kp`**
    *   从一个较小的 `Kp` 开始。给系统一个阶跃输入（例如，在Yaw轴测试中，让目标从0度突然变为90度）。
    *   观察图表。逐渐增大 `Kp`，直到你看到系统开始在目标值附近出现**持续、等幅的振荡**。这个振荡的输出曲线就是您寻找的临界状态。
    *   记下此时的 `Kp` 值，我们称之为 `Kcr` (临界增益)。
    *   观察图表上振荡的周期（一个波峰到下一个波峰的时间），记下这个周期 `Tcr` (临界周期)。

3.  **第二步：计算初始PID值**
    *   根据经典的Ziegler-Nichols整定表，您可以用 `Kcr` 和 `Tcr` 计算出一组相当不错的初始PID参数：
        *   **`Kp` = 0.6 * `Kcr`**
        *   **`Ki` = (1.2 * `Kcr`) / `Tcr`**
        *   **`Kd` = (0.6 * `Kcr` * `Tcr`) / 8**
    *   将这组计算出的值填入您的PID控制器。

4.  **第三步：微调**
    *   现在，您有了一组不错的起点。再次运行测试，观察图表，并根据以下规则进行微调，以达到最佳性能：
        *   **如果系统响应太慢**: 适当增加 `Kp`。
        *   **如果系统振荡或超调太大**:
            *   首先尝试增加 `Kd` 来抑制振荡。
            *   如果增加 `Kd` 效果不佳或导致抖动，再考虑减小 `Kp`。
        *   **如果系统稳定了，但有稳态误差（最终不回到0）**: 慢慢增加 `Ki`，直到误差被消除。
        *   **如果增加 `Ki` 后超调变大**: 尝试稍微减小 `Kp` 或增加 `Kd` 来平衡。

**观察图表的技巧**:

*   **理想曲线**: 一个理想的PID响应曲线应该像一个“S”型，快速上升，有一个小的超调（或没有），然后迅速稳定在目标值上。
*   **P控制器主导**: 曲线剧烈响应误差，但可能无法完全归零。
*   **PI控制器主导**: 曲线响应后，稳态误差被逐渐消除，但可能超调较大。
*   **PD控制器主导**: 曲线响应快，超调小，但可能有微小稳态误差。
*   **PID控制器**: 结合三者优点，快速、准确、平稳。
