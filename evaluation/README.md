# 评测结果说明

本目录保存与仓库内最终权重 `models/combine1014.pt` 对应的一组评测记录。结果分为三类，使用时必须区分口径。

## 结论

| 结果类型 | 数据 | 可用于说明 |
| --- | --- | --- |
| 训练期验证 | Precision 0.99098；Recall 0.99343；mAP@50 0.99497；mAP@50:95 0.88885 | 训练流程中验证集上的检测表现 |
| 无标注推理冒烟测试 | 2 张图片、20 个预测框；CPU 平均 2488.820 ms/图 | 权重可以加载并完成离线推理 |
| 仓库运行日志 | 2,566 次计时推理；平均 11.298 ms，中位数 11.014 ms，P95 13.049 ms | 原运行环境中的历史性能记录 |

仓库没有提供能够证明独立性且带完整标注的测试集，因此不能从现有材料计算独立测试集的 Precision、Recall、mAP 或各类别指标。两张示例图片上的预测框数量也不能当作真实目标实例数。

## 文件

- `summary.json`：评测条件、主要结果、限制和最终权重哈希。
- `inference_details.json`：两张示例图片的逐框预测与计时明细。
- `evidence/runs/`：两组训练期验证的参数和逐 epoch 指标。
